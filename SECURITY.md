# Security policy

This script changes SSH, firewall and user settings on servers, so security reports matter.

## Reporting a vulnerability

Please do not open a public issue. Use the "Report a vulnerability" button on the
[Security tab](https://github.com/mohamedtaqysalmi/server-bootstrap/security/advisories/new)
of this repository. That opens a private report that only I can see.

This is a solo-maintained project. I aim to reply within a few days, but I cannot promise a fixed response time.

## Supported versions

There is no release yet. Only the latest commit on `main` is supported.
